# Саныч-6 — изменения версии 3.0.0

## По замечаниям оператора

- Пятая кнопка нижней панели — «Технолог». Все шесть пунктов Android: РПД, определение притока, ПР → УПР, УПР → АПВ, СКО, температура ТМС. Старые ссылки на калькуляторы сохранены.
- Ручной замер: кнопки «Секунды» / «Минуты» с пересчётом значения; кнопка сохранения удалена. Валидный замер сохраняется после двух секунд без изменения, при остановке таймера, уходе с экрана и сворачивании. Текущий секундомер обновляет одну запись, новый после сброса создаёт новую; разные интервалы сохраняются отдельно.
- Таймер восстанавливается после закрытия вкладки или приложения с учётом прошедшего времени. В других разделах видна маленькая кнопка с временем замера и переходом к нему. Это окно внутри PWA: Safari не позволяет произвольно рисовать его поверх других приложений или экрана блокировки.
- Барабаны уменьшены с пяти до трёх видимых строк (132 px); рамка выбора неподвижна. Ближайшее значение выделяется непосредственно при прокрутке, без таймера задержки. Сохраняются выбранные даты, часы и минуты, в том числе после открытия новой вкладки.
- Расчёт уровня: глубина → Pз/Pд → плотность г/см³ → необязательное удлинение. Выбор единиц удалён. Данные старой формы в кг/м³ мигрируют в г/см³. Формула прежняя.
- Линейка уровня воспроизводит координаты Android, частота — значок спидометра. Обновлены остальные основные значки, «Q», «2А», «FF». Оригинальные PNG ручного замера, притока и охлаждения ПЭД сохранены. «Разгон» и «РИЧ» доступны отдельными пунктами главной страницы.
- ВНР: ползунок положения по всему документу; список закладок, добавление текущей страницы, переименование, удаление и открытие. Повторное добавление той же страницы не создаёт дубликат. Закладки хранятся на устройстве и работают офлайн.
- ВНР: окно загрузки закрывается крестиком; после загрузки не появляется автоматически. Вверху остаётся кнопка загрузки/проверки. По желанию можно обновить уже скачанные страницы из опубликованной версии; при ошибке загрузки сохранённая исправная страница не заменяется ответом HTML.
- Разгон/РИЧ: загрузка всех фотографий в отдельном закрываемом окне, кнопка вверху. Закрытое окно не навязывается снова; после успешной загрузки оно закрывается.
- Выбор ПЭД открывает и прокручивает карточку расчёта в видимую область; программный фокус не вызывает клавиатуру.
- Помощник оператора всегда открывает ответы с самого верха.
- Навигация связана с историей браузера: работают Back/Forward и поддерживаемые браузером жесты без потери форм. Внутренняя кнопка «Назад» сохранена.
- Версия PWA 3.0.0, отдельный кэш оболочки. Скачанные ВНР/фотографии и прежняя история при обновлении не удаляются.

## Android — закладки ВНР

Исходный `app/` восстановлен из всех проверенных частей отдельным коммитом. Вторым коммитом добавлены закладки в локальный HTML и сохранение через узкий JavascriptInterface в SharedPreferences. Добавлены размеры исходных страниц для стабильной прокрутки до загрузки изображений. Существующий нижний нативный ползунок сохранён; дополнительный HTML-ползунок скрыт. Электронный уровень и формулы Android не изменялись.

Проверка исходного Android HTML выполнена в Chromium с имитацией контракта хранилища; это не проверка APK, WebView или реального SharedPreferences. Сборка APK недоступна: в репозитории отсутствует `gradle/wrapper/gradle-wrapper.jar`; запущенный Gradle сообщает `Unable to access jarfile`. В текущем загруженном корневом build.gradle.kts также находится конфигурация модуля app, каталог версий загружен в корень вместо gradle/libs.versions.toml. Эти отдельные проблемы структуры сборки не исправлялись в рамках добавления закладок.

## Проверки и ограничения

Локально прошли 58 тестов (0 ошибок, 0 пропусков), дополнительно 6 сценариев готового dist по вложенному адресу. Сборка и проверка ресурсов успешны. Итоговые результаты — в `tests/V3_RESULTS.txt`, проверка статической сборки — `tests/V3_BUILD_RESULTS.txt`. Набор включает сверку с эталонными результатами оригинальных Kotlin-калькуляторов, старые рабочие сценарии и новые замечания. Android-специфическая проверка автоматически пропускается в CI PWA, где нет соседнего Android checkout; остальные проверки выполняются.

Выполнен визуальный просмотр экранов шириной 320 px в Chromium. Физический iPhone, Safari и системный жест в установленной PWA не проверялись. Нативное окно поверх других приложений средствами обычной PWA недоступно; время восстанавливается при возвращении. Данные браузера остаются локальными: очистка хранилища удаляет историю и закладки.

## Получение обновления без терминала

Дождитесь зелёного deploy в GitHub Actions. Откройте приложение с интернетом и перезагрузите страницу; если открыта старая версия, полностью закройте и снова откройте её. Проверьте «Справочник → О приложении → Версия 3.0.0». Удалять установленный значок и очищать данные сайта не требуется.
