# Версия 3.0.17 — чистые формы и выбор кабеля

- Каждый новый вход в расчётный раздел, включая «Назад», «Вперёд» и вход после
  перезагрузки, начинает новый расчёт. Удаляются черновик формы и сохранённый
  экран, а не записи в истории. Это относится к притоку, уровню, частоте,
  напору, отпайке, СКО, РПД, УПР/АПВ, коэффициенту 2А, потенциалу,
  температуре, охлаждению ПЭД и параметрам станций.
- Завершённый ручной замер при новом входе также очищается. Запущенный
  секундомер продолжает текущий замер при переходах и перезагрузке.
- Внутренние шаги настройки станции, выбор модели ПЭД и окно пояснений «?»
  относятся к одному процессу: поля во время такой работы не очищаются.
- История, закладки, загруженные документы и фотографии остаются сохранёнными.
- В геометрии притока добавлен выбор кабеля КПБП 3×16 или КППБПТ 3×16.
  Приложение подставляет соответственно 518,91 или 561 мм². Это площадь
  охватывающего прямоугольника по максимальным габаритам таблицы 9,
  а не точная площадь реального кабеля.
- Для другого кабеля можно ввести фактическую наружную площадь с изоляцией.
  Подпись объясняет, почему 16 и 48 мм² не являются наружной площадью
  изолированного кабеля 3×16. Пустое поле означает расчёт без кабеля.
- Справочное расчётное приближение ЭК 139,7 / НКТ 73 остаётся 0,0077 м³/м;
  выбор этой пары сохраняет режим «По справочнику».
- Публикация через GitHub Actions кэширует тестовый Chromium и устанавливает
  только используемую тестами версию без интерфейса. На первой установке
  оставлено больше времени для медленной загрузки браузера.

Обоснование коэффициента и ограничения приближения:
[расчёт Vкп](docs/VKP_139_7_73_RU.md).
