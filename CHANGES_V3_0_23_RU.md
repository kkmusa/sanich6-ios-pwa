# Изменения версии 3.0.23

- Устранён конфликт системного поворота экрана и ручного поворота регламента ВНР.
- Приложение больше не вызывает системный API ориентации и не реагирует на акселерометр программно.
- Регламент поворачивается и возвращается обратно только по кнопке; повторные быстрые нажатия обрабатываются стабильно.
