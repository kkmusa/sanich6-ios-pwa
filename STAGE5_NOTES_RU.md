# Этап 5 — сохранение живых экранов при навигации

- Для калькуляторов `level`, `frequency`, `flow`, `upr`, `apv`, `sko`, `tap` DOM-дерево временно отсоединяется и сохраняется в памяти при уходе со страницы. При возвращении оно подключается обратно без повторного вызова `render...()`.
- Сохраняются значения полей, выбранные варианты, результаты и обработчики событий; курсор не сбрасывается при переходах.
- История, справочник, экран ручного замера с таймером и прочие динамические экраны **не кэшируются**, чтобы не показывать устаревшие данные и не оставлять активный таймер.
- При перезагрузке PWA по-прежнему используется восстановление значений из sessionStorage, разработанное ранее.
- Математические формулы не менялись; обновлена версия ресурсов/офлайн-кэша до v13.
- Это не полная замена HTML-шаблонов на DOM-компоненты. Полевое тестирование в Safari iOS необходимо.
