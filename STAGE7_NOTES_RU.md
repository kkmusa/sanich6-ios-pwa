# Этап 7 — ручной замер для iPhone

- Новый отдельный `js/manual.js`, вместо встроенной в calculators.js логики.
- Секундомер и переключаемый режим временного интервала.
- Два независимых прямоугольных барабана (часы/минуты) для начала и конца, свайп с прокруткой и привязкой к строке.
- Начало: вчера/сегодня, конец: сегодня. Некорректные интервалы блокируются.
- Формула: м³/сут = литры × 1,44 / минуты.
- Сохранение каждого замера отдельной кнопкой в историю, без перезаписи предыдущего.
- Проверки: `node --test tests/*.test.cjs`.
- Важно: UI на реальном iPhone пока не тестировался. Время по умолчанию берётся из часов устройства.
