# Этап 6 — сохранение положения прокрутки при навигации

- При переходе из раздела запоминается его вертикальная позиция.
- При возврате кнопкой «Назад» восстанавливается прежняя позиция вместо принудительной прокрутки в начало.
- При новом переходе вперёд экран открывается с начала.
- Существующее сохранение полей и живых DOM-экранов не менялось.
- Версия кэша PWA и ресурсов обновлена до 14.
- Добавлены два регрессионных теста для поведения навигации.

Ограничения: сохранение прокрутки — внутри текущей сессии приложения, не между перезапусками; полное тестирование Safari/iPhone не проводилось. Остальные HTML-шаблоны пока не переработаны.
