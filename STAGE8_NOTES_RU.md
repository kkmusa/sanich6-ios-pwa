# Этап 8 — регламент ВНР в PWA

- Полные 207 страниц регламента (JPEG из Android-версии) доступны офлайн после первого открытия страниц.
- 338 интерактивных областей гиперссылок из PDF сохранены.
- Поиск с подсветкой, кнопками переключения совпадений и очисткой × встроен в просмотрщик.
- Кнопка «↑ Оглавление» переходит на страницу 3 (проверьте фактическое расположение оглавления на устройстве).
- Новый пункт «Регламент ВНР» расположен первым в справочнике.
- Service Worker кэширует оболочку и HTML регламента при установке; изображения страниц кэшируются по мере открытия.
- ВАЖНО: без предварительной загрузки всех страниц полный документ офлайн недоступен. Нужна отдельная стратегия предзагрузки с контролем квоты Safari.
- Android-формулы и таблицы сохранены как изображения; на iPhone следует проверить читаемость и увеличение.
- Не проверено на реальном iPhone; это исходный проект для тестирования.
