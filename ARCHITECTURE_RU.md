# PWA «Оператор ДНГ»: архитектурная переработка, этап 1

Существующая функциональность и формулы сохранены без переписывания.

- `js/core.js` — состояние, история, навигация, общие компоненты.
- `js/calculators.js` — экраны расчётов.
- `js/reference-data.js` — нормативные и справочные данные.
- `js/reference-ui.js` — справочник и навигация по нему.
- `js/ped.js` — база ПЭД и связанные экраны.
- `js/bootstrap.js` — маршрутизация и запуск.
- `legacy/app.original.js` — исходный монолит для сверки.

Исправлено: введённые значения полей запоминаются в оперативной памяти для каждого маршрута и восстанавливаются при возвращении. Временное состояние не пишется в localStorage; история по-прежнему хранится там, как в исходной версии.

Важно: это промежуточный безопасный этап, не полная компонентная архитектура. HTML-строки внутри экранов пока остались. Полная замена рендера потребует отдельных регрессионных тестов каждого калькулятора. Версия не содержит переноса новых Android-функций и полного регламента ВНР.

Проверка: `node --check js/*.js` по отдельности; для ручной проверки использовать HTTP-сервер, не открывать index.html через file://. На iPhone требуется отдельное тестирование Safari и автономной установки.
