# Архитектура PWA «Саныч-6», web.22

Приложение работает как набор статических файлов. Производственная версия не требует npm, серверной логики или сборочного фреймворка; инструменты npm используются для тестов, проверки комплектности и подготовки `dist/`.

| Файл | Ответственность |
| --- | --- |
| `js/math.js` | Чистые формулы и проверка аргументов, совместимое с Android округление; CommonJS-экспорт для тестов |
| `js/core.js` | Состояние маршрутов, история, черновики форм, выбранные варианты, сохранённые экраны и прокрутка |
| `js/ui-components.js` | Общие поля, карточки результатов, панели навигации |
| `js/calculators.js` | Главная, «Технолог», UI уровня/частоты/притока/СКО/отпайки/циклов/истории |
| `js/engineering.js` | UI коэффициента 2А, температуры ТМС, потенциала и РПД |
| `js/manual.js` | Секундомер с сохраняемой сессией, календарный интервал, колёса, сохранение замера |
| `js/ped.js` | Загрузка базы, фильтры и состояние выбора ПЭД, расчёт охлаждения и экраны справочной информации |
| `js/reference-data.js` | Данные труб, передачи запуска ВНР и 12 тем помощника |
| `js/reference-ui.js` | Справочник и подключение просмотрщика ВНР |
| `js/operator-data.js` | Неизменённые 75 шагов инструкций станций |
| `js/operators.js` | Ввод режима, сохранение параметров/шага, показ инструкций, загрузка фото |
| `js/bootstrap.js` | Первый запуск, маршрутизация, начало приложения |
| `vnr/search-data.js` | Исходные координаты 64 169 слов 207 страниц |
| `vnr/reader.js` | Поиск слов и фраз, подсветка, переходы, сохранение состояния документа |
| `vnr/toolbar.js` | Счётчик, стрелки, очистка, оглавление, выбор страницы и масштаб |
| `vnr/offline.js` | Сообщения Service Worker, прогресс, тайм-ауты и ошибки загрузки ВНР |
| `sw.js` | Версионированная оболочка и отдельные кэши документа/фотографий |
| `scripts/` | Проверка ресурсов, статическая сборка, аудит Android, генерация JVM-эталонов |
| `tests/` | Математические, JVM-parity, браузерные и Service Worker проверки |

Файлы приложения подключаются последовательно обычными script-тегами. Между ними сохранены именованные интерфейсы; порядок подключений указан в `index.html`. Все расчётные функции отделены от DOM. Материалы ВНР и инструкции вынесены в отдельные файлы данных.

Существующие ключи истории `operator_dng_history_v1` и кэшей документа/фотографий сохранены для совместимости. Черновики форм, варианты СКО/ЧРП, фильтры ПЭД, параметры станций и состояние ВНР хранятся в sessionStorage. История, отметка о политике и сессия секундомера — в localStorage. Ошибки хранилища не останавливают расчёты; неуспешная запись истории отображается пользователю.

Калькуляторы сохраняют живые DOM-экраны при переходах, а черновики восстанавливают поля и зависимые переключатели после перезагрузки. У секундомера отдельно сохраняется логическое состояние: визуальный interval отключается при уходе, отсчёт продолжается и восстанавливается при возвращении. Явное сохранение и автоматическое сохранение одного замера при выходе согласованы.

Service Worker использует `operator-dng-pwa-v22` для оболочки, `operator-dng-vnr-pages-v1` для страниц и `operator-dng-photos-v1` для фото. Активация новой оболочки удаляет только старые кэши оболочки; материалы сохраняются. Предварительная загрузка возобновляется с сохранённых файлов. Ответ HTML вместо изображения не засчитывается как скачанная страница. Ошибка свободного места показывается отдельно. Внешние веб-ссылки документа требуют сети.


## Изменения версии 3.0.0

`vnr/bookmarks.js` управляет закладками и ползунком; PWA сохраняет закладки в localStorage, Android использует адаптер JavascriptInterface → SharedPreferences. Навигация в core.js связана с History API браузера; историю расчётов читает calculationHistory(), чтобы не перекрывать window.history. manual.js хранит таймер и текущую сессию замера между перезапусками и рисует мини-панель в других разделах. Офлайн-окна находятся в vnr/offline.js и operators.js. Подробности поведения: CHANGES_V3_RU.md.
