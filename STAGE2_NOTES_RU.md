# Этап 2 — стабильность PWA

- Черновики полей сохраняются отдельно по экранам в `sessionStorage` при вводе и смене раздела.
- После перезагрузки вкладки значения полей восстанавливаются; после закрытия браузерной сессии сохранение не гарантируется.
- Ввод больше не требует полной перерисовки экрана: сохраняется позиция курсора.
- Service Worker обновлён до v10: навигация — сеть с офлайн-резервом, ресурсы — кэш с загрузкой при отсутствии. Ошибка сети для картинки/скрипта больше не подменяется HTML-документом.
- Версии ресурсов в index.html и precache согласованы.

## Ограничения

Визуальные экраны пока остаются шаблонными HTML-строками. Перенос функций из Android и полный регламент ВНР в этот этап не включены. Тестов в реальном Safari/iPhone не было.
