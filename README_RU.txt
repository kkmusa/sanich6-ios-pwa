Оператор ДНГ — PWA версия

Что это:
- веб-приложение для iPhone и Android;
- после первой загрузки основные файлы кэшируются и приложение работает без интернета;
- история расчётов и отметка о политике конфиденциальности хранятся локально в браузере;
- сервер для расчётов не нужен.

Как проверить на компьютере:
1. Нельзя просто открыть index.html двойным кликом: Service Worker требует http/https.
2. В папке проекта выполнить:
   python3 -m http.server 8080
3. Открыть в браузере http://localhost:8080

Как выложить бесплатно:
Можно разместить эти статические файлы на GitHub Pages, Cloudflare Pages или другом HTTPS-хостинге.

Установка на iPhone:
1. Один раз открыть адрес приложения в Safari при наличии интернета.
2. Нажать «Поделиться».
3. Выбрать «На экран Домой».
4. После установки открыть приложение один раз с интернетом для полного кэширования.
5. Далее основные расчёты работают офлайн.

Текущая версия прототипа переносит основные расчёты Android-приложения:
- уровень жидкости;
- необходимую частоту запуска;
- приток (таблица/геометрия, 3 режима);
- ручной дебит с таймером;
- отпайку ТМПН;
- ПР → УПР;
- УПР → АПВ;
- СКО;
- историю расчётов;
- справочник ЭК;
- экран «О приложении»;
- политику конфиденциальности;
- первый экран уведомления о конфиденциальности.
