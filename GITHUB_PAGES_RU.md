# Открыть «Оператор ДНГ» на телефоне

Сборку и публикацию выполняет GitHub. Устанавливать программы на компьютер и вводить команды не нужно.

После успешной публикации доступны три ссылки:

- **Обычная версия:** https://kkmusa.github.io/sanich6-ios-pwa/
- **Опер ДНГ рег — инструкции по документам:** https://kkmusa.github.io/sanich6-ios-pwa/reglament/

- **Опер ДНГ без — без раздела аварийных остановок:** https://kkmusa.github.io/sanich6-ios-pwa/bez/

Названия при установке: «Оператор ДНГ», «Опер ДНГ рег», «Опер ДНГ без». Все три можно установить на один телефон. Регламент и фотографии
для офлайн-работы загружаются отдельно в каждом приложении.

## Однократная настройка

1. Откройте https://github.com/kkmusa/sanich6-ios-pwa/settings/pages под владельцем репозитория.
2. В разделе **Build and deployment** выберите **Source → GitHub Actions**. Если GitHub предлагает выбрать шаблон, это не требуется: готовый workflow уже находится в репозитории.
3. Откройте https://github.com/kkmusa/sanich6-ios-pwa/actions . При первом открытии, если появится предложение включить Actions, нажмите **I understand my workflows, go ahead and enable them**.
4. Слева выберите **Publish Operator DNG**, затем **Run workflow**, ветку **main** и зелёную кнопку **Run workflow**.
5. Откройте появившийся запуск. Дождитесь зелёных отметок у **build** и **deploy**. Обычно это занимает несколько минут. Сборка проверяет расчёты, интерфейс, офлайн-ресурсы и итоговые файлы; публикация происходит только после успешных проверок.
6. Откройте **Settings → Pages → Visit site**. Ссылку также можно открыть в блоке **github-pages** на странице запуска.

Ожидаемый адрес при стандартных настройках: https://kkmusa.github.io/sanich6-ios-pwa/ . Ориентируйтесь на фактическую ссылку **Visit site**: до первого успешного deploy сайт может возвращать 404.

После следующих изменений ветки **main** обновление публикуется автоматически. Вручную запускать сборку больше не нужно.

## На телефоне

- **iPhone:** откройте ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Android:** откройте ссылку в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Первый запуск выполните с интернетом. В приложении предварительно загрузите регламент ВНР и фотографии для работы без сети. Дождитесь завершения загрузки, затем проверьте нужные разделы в авиарежиме. Safari может удалять данные сайта при нехватке памяти; после очистки потребуется повторная загрузка.

## Если публикация не включается

- Для **приватного** репозитория доступность GitHub Pages зависит от тарифа GitHub. Если **Settings → Pages** предлагает обновить тариф, потребуется подходящий тариф. Не меняйте видимость репозитория, если не хотите раскрывать исходники.
- Если Actions запрещены, владелец должен разрешить их в **Settings → Actions → General**. Политики организации могут потребовать участия администратора.
- Красный **deploy** после успешного **build**: проверьте **Settings → Pages → Source: GitHub Actions**, затем откройте неуспешный запуск → **Re-run jobs → Re-run failed jobs**.
- Если **github-pages** требует одобрения, нажмите **Review deployments** в запуске и подтвердите публикацию, если вы владелец с нужными правами.
- Красный **build**: откройте неуспешный шаг и сохраните текст ошибки. Сайт не заменяется непроверенной сборкой.

GitHub Pages публикует статические файлы приложения. Не добавляйте в них пароли, токены или конфиденциальные данные. Репозиторий остаётся приватным; доступность самого сайта зависит от настроек Pages и тарифа.
