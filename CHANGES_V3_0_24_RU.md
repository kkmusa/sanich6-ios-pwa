# Изменения версии 3.0.24

- Результат ручного замера во время работающего секундомера фиксируется при вводе литража и меняется только после нового ввода; секундомер продолжает идти независимо.
- Новые круги ручного замера выводятся сверху, старые смещаются вниз.
- Добавлена проверка секундомера по реальному времени устройства.
- В расчёте импортных УЭЦН паспортная частота зафиксирована на 60 Гц и убрана из формы; иконка заменена на бело-оранжевую `DN`.
- Кнопка ручного поворота ВНР сделана контрастнее и заметнее.
- Значок приложения уменьшен внутри безопасного жёлтого поля, чтобы системная маска телефона не приближала и не обрезала логотип.
- Расчёт уровня разделяет вертикальный уровень и уровень по стволу; добавлен необязательный пересчёт по двум соседним точкам таблицы инклинометрии.
