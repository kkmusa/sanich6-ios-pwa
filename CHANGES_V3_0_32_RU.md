# Версия 3.0.32

- Во вкладку «Технолог» добавлен расчёт динамического уровня по датчику МРМ с переносом рабочей VBA-модели из таблицы.
- Расчёт цикла УПР дополнен временем работы и накопления, ориентировочными уставками давления и средней мощностью.
- Добавлены корректировка периодической программы, мощность и УРЭ, потери в кабеле, выбор НКТ, коэффициент подачи и оценка уменьшения глубины спуска УЭЦН.
- Для установок 2А добавлен объединённый пересчёт частоты станции, подачи и напора.
- Ручной замер получил явную кнопку сохранения, сохранение кругов, новые круги сверху и показ времени словами; «Сброс» очищает весь текущий замер.
- Все новые расчёты сохраняются в истории и снабжены пояснениями по кнопке «?». Android-версия не изменялась.
