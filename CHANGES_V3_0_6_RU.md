# Оператор ДНГ — 3.0.6

После «Ручного замера дебита» добавлен расчёт «Напор на частоте».
Паспортный напор указывается в метрах при 50 Гц, рабочая частота — в герцах.
Формула предоставлена автором: H = H₅₀ × (f / 50)².
Пример: 2100 м при 54 Гц → 2449,44 м. Частота 0 Гц даёт 0 м;
нулевой/отрицательный паспортный напор, отрицательная частота, пустые,
нечисловые и бесконечные значения отклоняются.

Добавлены пояснение по «?», автоматический результат и история. Поля и
результат сохраняются при переходах; черновик восстанавливается после
перезагрузки в той же сессии браузера. Калькулятор включён в офлайн-оболочку.

В иконке РИЧ вторая F уменьшена. Иконка «Технолог» в нижней панели заменена
на циркуль Architecture, как в Android. Версия оболочки и кэша — 3.0.6;
скачанные материалы и пользовательская история при обновлении не очищаются.
