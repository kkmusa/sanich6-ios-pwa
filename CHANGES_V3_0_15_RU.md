# Версия 3.0.15 — углублённая проверка

- Табличные 0,0100 м³/м для ЭК 139,7 / НКТ 73 исключены из вычислений.
  При выборе этой пары приложение переключается на геометрию, сохраняет
  размеры и требует выбрать стенку. Угаданного заменяющего коэффициента нет.
- В геометрии можно учесть наружную площадь всего кабеля. Пустое поле
  означает расчёт без кабеля; отрицательная площадь или вытеснение всего
  кольцевого пространства не дают результата.
- Отрицательный приток проверяется до округления, включая малые отрицательные
  значения, которые раньше выглядели как ноль.
- Старая история для ошибочной пары отмечена «Требует пересчёта», без удаления
  записей и подстановки выдуманных исправленных результатов.
- РПД отклоняет переполнение промежуточных вычислений и отрицательную границу
  отключения. Результаты с работой менее 3 минут или диапазоном менее 1 атм
  отмечаются по рекомендациям ВНР §11.11.4 и не сохраняются как готовый режим.
- Уточнены единицы давления, вертикальный смысл уровня, паспортный напор
  при 50 Гц, номинальный ток ПЭД и напряжения в расчёте отпайки.
- Удлинение не может быть отрицательным или превышать глубину спуска.
- Для инструкций станций, использующих ч:мин, запрещено скрытое округление
  дробных периодов; смена станции сразу обновляет проверку. Положительные
  величины не превращаются в нулевые настройки из-за точности отображения.
