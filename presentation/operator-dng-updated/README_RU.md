# Оператор ДНГ — правки вступления, автора, интервала и финала

1. Встроенное вступление поясняет назначение: кроссплатформенное приложение для Android и iOS, для работников Общества и подрядных организаций.
2. На слайде 3 главный заголовок — «АВТОР ПРОЕКТА», ФИО уменьшено относительно него.
3. При переходе к целям отключена «Трансформация», используется короткое затухание. Объекты номеров слайдов имеют разные имена, чтобы не провоцировать сопоставление.
4. На слайде 8: «Время замера можно задать интервалом», указание начала и окончания вместо акцента на полуночи.
5. Слайд 20: «СПАСИБО ЗА ВНИМАНИЕ».

Второй слайд совпадает с последним декодированным кадром нового ролика; переход отключён. В PPTX встроен только один обновлённый MP4. Остальные тексты, фотофоны, 250 силуэтов и 20 навигационных ссылок сохранены.

Откройте PPTX в настольном PowerPoint и начните показ с первого слайда. При необходимости запустите видео щелчком. PDF содержит статичный кадр вместо видео. Реальное воспроизведение и переходы в Microsoft PowerPoint в облачной среде не проверены.

Вёрстка просмотрена через PDF, настройки перехода и медиавложения проверены по структуре файла. Фоновые изображения являются иллюстрациями, созданными ИИ, а не документальными фото объектов компании. Портрет обработан по фотографиям автора.

Последние правки: на слайде 20 убрано название приложения (крупное и в верхней строке); на слайде 6 удалены все 12 гиперссылок с карточек. Восемь обратных ссылок «Все инструменты» сохранены.

Начало обновлено: до пролёта только «ОПЕРАТОР ДНГ», без пояснений, служебных подписей и полосы. Пояснение приложения появляется после раскрытия промысла. Стык заново совмещён с финальным кадром. Остальные 19 слайдов сохранены без изменений.
