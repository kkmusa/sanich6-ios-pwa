# Презентация «Саныч-6» — новая подача v3

Основной файл: **Sanich6_Cinematic_v3.pptx**. Открыть в Microsoft PowerPoint → Показ слайдов → С начала. Для трансформаций нужна поддержка Morph. PDF и Quick Look не показывают переходы.

**Sanich6_Motion_Preview.mp4** — отдельно отрисованный аниматик по сценам, не запись воспроизведения PowerPoint.

**Sanich6_Cinematic_v3_complete.zip** — весь комплект: PPTX, PDF, аниматик, Excel, сценарий, источники и паспорт проекта.

Скачать: откройте файл и нажмите **Download raw file** (стрелка вниз). Для приватного репозитория войдите в аккаунт с доступом.

24 слайда основного показа (включая этапы трансформаций), 5 резервных. Проверены структура и геометрия движущихся объектов, статический экспорт и размещение. Воспроизведение в установленной версии Microsoft PowerPoint ещё нужно проверить. Старые файлы v2 сохранены.
