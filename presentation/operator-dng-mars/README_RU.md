# Оператор ДНГ — вступление по образцу «Марса»

Скачайте OperatorDNG_Mars_Presentation.pptx, откройте локально в PowerPoint 2021 и запустите показ с первого слайда.

## Что изменено

На первом слайде встроен девятисекундный ролик: раскрытие названия слева направо → пауза на изображении внутри букв → приближение сквозь букву → раскрытие промысла и появление подзаголовка.

Видеофрагмент находится внутри PPTX. Внешний MP4 для выступления и интернет не нужны. Запуск настроен автоматически. Если PowerPoint не начинает воспроизведение, щёлкните по изображению. После окончания перейдите дальше обычным щелчком или стрелкой вправо. Остальные слайды редактируются как прежде; только кинематографическое вступление стало видео.

Отдельный OperatorDNG_Mars_Intro.mp4 — то же вступление, его можно посмотреть заранее.

## Проверки и ограничения

Проверены: видеопоток H.264, 1920×1080, 30 кадров/с, длительность 9 с; наличие видео внутри ZIP-структуры PPTX; совпадение контрольных сумм встроенного видео и исходного MP4; настройка старта без задержки; сохранение 22 слайдов, включая скрытый справочный.

Фактическое воспроизведение в Microsoft PowerPoint в облачной среде не проверено. PDF не воспроизводит видео. Первоначальный вариант зависел от увеличения векторной маски в 110 раз; он заменён встроенным роликом для более предсказуемого движения. Это новый способ реализации, а не подтверждение точного совпадения с референсом.

Изображение промысла — иллюстрация, созданная ИИ, не фотография объекта компании. Портрет автора обработан ИИ по предоставленным фотографиям.
