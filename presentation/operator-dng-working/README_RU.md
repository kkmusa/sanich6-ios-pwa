# Оператор ДНГ — рабочая презентация

21 основной слайд, 2 скрытых запасных. Утверждённое вступление по референсу «Марс» сохранено. Чёрный, белый, жёлтый #FFCD00. Четыре задачи взяты из согласованного текста; полные пояснения находятся в заметках и отдельном Word-файле.

## Как открыть
Открыть OperatorDNG_Working_Presentation.pptx в Microsoft PowerPoint. «Показ слайдов → С начала». Листать щелчком или стрелкой. В PDF, Quick Look и предпросмотре GitHub анимации нет. Для скачивания с GitHub нажать Download raw file (стрелка вниз) после входа в свой аккаунт.

Для запланированного движения нужен PowerPoint с поддержкой «Трансформация / Morph». Для старого Office предусмотрен запасной сдвиг Push; он не воспроизводит эффект буквенной маски. Воспроизведение в настоящем Microsoft PowerPoint здесь не проверено.

## Навигация
На слайде 5 четыре карточки открывают свои разделы. В разделах сверху справа — «Все инструменты». На изображении ручного замера и регламента можно нажать для перехода к увеличенному фрагменту и обратно. Всего проверено 26 внутренних действий.

## Что входит
- PowerPoint — редактируемый файл, включая текст, карточки, векторную маску и переходы.
- PDF — 21 страница основного показа, без анимации.
- OperatorDNG_Speaker_Notes.docx — заметки для выступления на русском языке.
- OperatorDNG_Business_Case.xlsx — модель оценки эффекта. Неизвестные значения нужно подтвердить; вымышленные ставки и суммы не подставлялись. 17 исходных формул сохранены.
- Opening_Preview.mp4 — только 11-секундный независимый аниматик вступления, не запись PowerPoint и не видео всей презентации.
- VALIDATION.json — результаты доступных проверок.
- Исходники построения и материалы для воспроизводимости.

Фото автора, точные ФИО, должность и цех не предоставлены. Под них оставлен скрытый слайд 22; в основной показ заполнитель не попадает. Показ слайдов заканчивается на слайде 21.

## Достоверность
Промысловое изображение создано для оформления; это иллюстрация, не фотография объекта компании. Фотография станции взята из Android-проекта, её значения не являются рекомендуемыми настройками. Скриншоты PWA реальные; внутри презентации это изображения, не интерактивные расчётные формы. Официальный логотип компании не подставлялся; корпоративное утверждение проекта не заявляется.

Три месяца, минимальные прямые денежные расходы и потенциальная аудитория около 250 человек — сведения автора. Частота 7–9 замеров относится к отдельным дням по его опыту, не ко всем сотрудникам. Снижение риска ошибок — ожидаемый эффект для проверки пилотом, не доказанный результат внедрения. Цены ремонтов и суммы сохранённой добычи не выдумывались.

ВНР и документы ПБ и ОТ в пяти томах разделены. Полнота интеграции всех томов и актуальность редакций не подтверждены. RosPump не представлен как интегрированная система. Приложение не управляет оборудованием и не заменяет действующие инструкции.

Проверены структура PPTX, имена объектов, цели внутренних переходов, сохранение согласованных задач и геометрии вступления, изменение размеров карточек и кадрирования, примеры расчётов, экспорт PDF и отсутствие обрезанного текста/наложений отдельных текстовых блоков. Основные слайды просмотрены в экспорте LibreOffice. Реальный iPhone, Android и проигрыватель Microsoft PowerPoint этой работой не испытаны.
