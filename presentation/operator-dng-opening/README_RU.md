# Оператор ДНГ — новое вступление по референсу «Марс»

Только три кадра вступления, не полная презентация.
Палитра: чёрный, белый, жёлтый #FFCD00. Без синих панелей и кругового декора.

1. Производственная иллюстрация внутри букв «ОПЕРАТОР ДНГ».
2. Увеличение отверстия в векторной маске раскрывает то же изображение на весь экран.
3. Изображение уменьшается и сдвигается вправо, слева появляется цель проекта.

PowerPoint: открыть OperatorDNG_Opening.pptx, «Показ слайдов → С начала».
Нужен PowerPoint с поддержкой «Трансформация / Morph». При отсутствии поддержки используется запасной сдвиг Push, который не повторяет эффект маски. Не оценивать движение по PDF или предпросмотру GitHub.

OperatorDNG_Opening_Preview.mp4 — независимый аниматик, отрисованный браузером по тем же контурам и положениям. Это не запись воспроизведения Microsoft PowerPoint. Файл явно помечен. В настоящем PowerPoint воспроизведение здесь не проверено.

PPTX и три страницы PDF проверены. Изображение промысла сгенерировано для оформления, не является фотографией объекта ООО «РН-Юганскнефтегаз». Сохранено отдельно без редактирования. Цветовая концепция не заявляется утверждённым корпоративным шаблоном; официальный логотип не подставлялся.

Векторная маска, текст и размеры изображения редактируются в PowerPoint. Основной эффект реализован масштабированием одной и той же фигуры, а не простой сменой статичных снимков.
