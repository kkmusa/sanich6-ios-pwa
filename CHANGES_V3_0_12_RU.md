# Версия 3.0.12

Из справки «?» расчёта РПД в «Опер ДНГ рег» удалён раздел
«Откуда брать исходное время работы» вместе с его пояснениями.
После вводного абзаца справка начинается с «Что вводим в расчёт».

Сохранены 11 шагов, 12 формул, числовой пример и остальные пояснения.
Обновлена версия офлайн-кэша для доставки изменения установленным PWA.

Дополнительная проверка расчётов:

- Подбор ПЭД повторяет Android: неподходящие записи с неположительным
  номинальным притоком исключены, подходящие отсортированы по убыванию
  притока. Для несовместимой пары ПЭД/ЭК выводится понятное сообщение.
- Ошибка или переполнение расчёта охлаждения не показываются как готовый
  результат. Нулевой рабочий ток по исходной формуле даёт нулевой приток.
- Отрицательный приток во время слива не записывается в историю и
  сопровождается просьбой проверить параметры. Сама формула сохранена.
- Уточнено значение Hст в справке, в историю расчёта добавлено введённое Hст.
- Коэффициенты исходных таблиц сохранены. Предупреждение и предложение
  переключиться на геометрию не добавлены по просьбе пользователя.
- Добавлены проверки материального баланса, геометрии, 24 дополнительных
  наборов РПД из исполняемого Kotlin и проверки подбора ПЭД во всех версиях.

Подробности и ограничения источников:
[аудит расчётов](docs/CALCULATION_AUDIT_V3_0_12_RU.md).
